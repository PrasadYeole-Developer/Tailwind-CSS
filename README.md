# Portfolio Website & Landing Page

This repository contains two projects: a **Portfolio Website** and a **Landing Page**, both designed with **Tailwind CSS** for a clean, responsive, and modern look.

## 📂 Project Structure

```
📦 Project Root
├── 📁 Portfolio-Website
│   ├── 📄 index.html
│   ├── 📄 style.css
│   └── 📁 assets
│
└── 📁 Landing-Page

    ├── 📄 style.css

```
